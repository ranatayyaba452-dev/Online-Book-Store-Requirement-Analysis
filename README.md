# Online Book Store – Requirement Analysis

## Project Description
This repository contains the Requirement Analysis document for the **Online Book Store** project. The document explains the project overview, user expectations, functional requirements, use case diagram, non-functional requirements, user stories, acceptance criteria (Gherkin), sprint planning, and conclusion. The purpose of this project is to understand the Requirement Analysis phase of the Software Development Life Cycle (SDLC).

## Contents
- Project Overview
- User Expectations
- Functional Requirements
- Use Case Diagram
- Non-Functional Requirements
- User Stories
- Acceptance Criteria (Gherkin)
- Sprint Planning
- Conclusion
